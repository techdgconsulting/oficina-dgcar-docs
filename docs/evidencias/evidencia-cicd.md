# Evidencia - CI/CD

Evidencias esperadas:

- PR aberta em cada repositorio tecnico.
- Check `validate` aprovado.
- Branch `main` protegida.
- PR obrigatorio para merge.
- Environment `homolog` com aprovacao manual.
- Environment `prod` com aprovacao manual.
- Workflow manual de deploy ou apply executado com sucesso.

Repositorios:

- `oficina-dgcar-api`;
- `oficina-dgcar-auth-lambda`;
- `oficina-dgcar-infra-db`;
- `oficina-dgcar-infra-k8s`.
