# Evidencia - Observabilidade

Evidencias esperadas no New Relic:

- dashboard de latencia por endpoint;
- dashboard de taxa de erro;
- metricas de CPU e memoria do Kubernetes;
- healthcheck e uptime;
- logs JSON com `correlationId`;
- erro controlado rastreavel por correlation-id;
- metrica de volume diario de OS;
- metrica de tempo medio por status.
