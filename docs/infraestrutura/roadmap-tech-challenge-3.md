# Roteiro Interno De Adequacao - Tech Challenge 3

Este documento e um apoio interno de organizacao do trabalho. Ele nao representa status formal da entrega, backlog oficial nem lista de pendencias da documentacao principal.

A documentacao formal do Tech Challenge 3 esta concentrada nos seguintes artefatos:

- diagrama cloud alvo em [`docs/arquitetura/cloud-target-architecture.puml`](../arquitetura/cloud-target-architecture.puml);
- RFCs em [`docs/rfc`](../rfc);
- ADRs de evolucao corporativa em [`docs/adr`](../adr), especialmente `ADR-013` a `ADR-018`;
- requisitos atualizados em [`docs/requisitos/especificacao-requisitos.md`](../requisitos/especificacao-requisitos.md);
- README do projeto.

O objetivo deste roteiro e apenas orientar a sequencia de trabalho da equipe durante a evolucao incremental do projeto do Tech Challenge 2 para o Tech Challenge 3. Sempre que houver divergencia, prevalecem os artefatos formais de arquitetura, requisitos e decisoes.
