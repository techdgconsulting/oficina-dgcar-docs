# New Relic

New Relic foi definido como ferramenta de observabilidade para centralizar metricas, logs, traces, dashboards e alertas.

## Escopo

- Aplicacao Spring Boot.
- Cluster Kubernetes.
- API Gateway.
- Lambda Auth CPF.
- Fluxos de negocio de ordens de servico.

## Sinais Monitorados

- Latencia HTTP por endpoint.
- Erros 4xx e 5xx.
- CPU e memoria de pods.
- Reinicios de pods.
- Saturacao de HPA.
- Healthchecks e uptime.
- Falhas em pagamento, notificacao e integracoes.

## Integracoes Previstas

- Agente Java na API Spring Boot.
- Coleta de logs JSON.
- New Relic Kubernetes Integration.
- Metricas customizadas da aplicacao.
- Dashboards para operacao e apresentacao.
