# RFCs

Request for Comments usados para registrar decisoes tecnicas relevantes antes da consolidacao arquitetural.

RFCs principais:

- escolha da nuvem AWS;
- uso de PostgreSQL gerenciado;
- autenticacao externa por CPF e senha com Lambda;
- estrategia de observabilidade com New Relic;
- separacao dos repositorios;
- separacao de Terraform DB e Terraform K8s.
